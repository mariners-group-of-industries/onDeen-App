Gamification module

The real capture starts after a seeded session is marked complete. The user sees the XP reward, streak state, category progress, and first-level unlock before continuing into the next post-session step.

A1

How to test: log in as the seeded user, open the booked Friday Community Iftar event, and complete attendance with the available QA completion path.

User + organiser story

Session feedback screen

The feedback flow starts after the reward journey and closes the loop by showing the organiser the submitted session feedback inside Event details.

How to test: complete the seeded Friday Community Iftar session, continue past the gamification screens, fill in the feedback form, then open the same event in the organiser app.

Guest flow

Guest booking flow

Guest booking lets a non-account visitor reserve a free event quickly while clearly explaining that XP and progress tracking start only after account creation.

A3

How to test: open the guest booking path for Seed: Friday Community Iftar, enter guest details, continue as guest, then open the generated e-ticket.

What to present: guest booking form, no-account notice, booked confirmation, view e-ticket action, QR ticket, venue, date/time, free admission, and download option.

Delivered value: first-time attendees can book a free event without signup friction, while OnDeen still records a usable guest ticket for attendance.

User app - guest booking form for a free event
User app - guest ticket booked confirmation
User app - guest e-ticket with QR code and venue details
User app story

Online session check-in codes

Online events give booked users a dedicated check-in path from the event details page. The code entry screen explains what is needed and returns clear validation when the code is early or incorrect.

A4

How to test: open the booked Beginner Quran Circle event and tap Enter online check-in code.

What to present: event details entry point, the online check-in code screen, the not-time-yet message, and the wrong-code message.

Delivered value: users can reach online attendance from the event, understand where to enter the organiser's code, and receive readable error feedback before a valid check-in.

Organiser + user story

Editable event titles from mobile app

Organisers can correct event titles directly from the mobile Event details screen, and the updated title is reflected back in the user-facing event list.

A6
B1.4

How to test: open Seed: Friday Community Iftar in the organiser app, tap Edit in the Event title card, rename it to Seed: Friday Community Iftar Update, save, then check the user app home list.

What to present: original organiser title, inline mobile edit mode with Cancel and Save, saved organiser Event details state, and the updated title visible in the user app.

User app story

Event share deep links

Users can share an event directly from Event details. The share flow builds a rich message with the event image and key details so the recipient understands what is being shared before opening any link.

B3.2

How to test: open Seed: Friday Community Iftar in the User app, tap the share icon, choose WhatsApp, and send the generated event message.

What to present: the in-app share sheet opens from Event details, then WhatsApp receives a pre-filled message with the event photo, title, organiser, date, Google Maps location link, and topic.

Delivered value: sharing is not just a raw URL; it becomes a readable invitation that can drive discovery, trust, and bookings from outside the app.

User app - Share sheet opened from Event details
WhatsApp - generated event message with image and key details

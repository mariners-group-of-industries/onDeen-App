# REFS seed assets

These files support the backend `refs` seed profile.

- Category icons are copied from the existing React Native User app assets.
- Posters and avatars ending in `reference-crop.png` are mechanical crops from
  the sacred User App reference-video frames.
- Crops are suitable for deterministic QA/demo parity, not a claim that the
  original high-resolution production artwork has been recovered.
- Replace a crop only when the Product Owner supplies the matching original;
  never substitute unrelated generic artwork.
- `knowledge-class-pre-read.pdf` is the rendered pre-read/summary fixture for
  the reference Event Material flow; its editable source is retained beside it.
- `knowledge-class-audio-recap.mp3` is the short spoken recap fixture used to
  prove audio material delivery without relying on an external host.
- No payment asset or payment record is activated by this seed profile.
